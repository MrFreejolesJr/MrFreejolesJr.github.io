# Calculadora de becas y financiamiento estudiantil
## by Ramses Omar Nuñez Hernandez
En esta pagina el usuario es capaz de calcular el costo de su proxima colegiatura y financiarla en pagos a meses con un 10% de interes mensual, tomando en cuenta la beca que se le otorga segun su calificación, dando como resultado el total a pagar con impuestos agregados y el pago mensual que se realizará
